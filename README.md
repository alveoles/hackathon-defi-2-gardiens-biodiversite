# Défi 2 — Les gardiens de la biodiversité

> Hackathon Alvéoles × Epitech — mercredi 2 décembre, TechSud (Saint-Pierre)

## Le défi

Développer un outil de **reconnaissance photo** d'une sélection de **4 à 5 plantes endémiques de La Réunion**.

## Objectif

Prendre une photo d'une plante et savoir s'il s'agit de l'une des espèces endémiques sélectionnées, et laquelle.

## Livrable attendu

- Un modèle de reconnaissance qui fonctionne
- Une démo live : photo → espèce identifiée
- Un README qui explique comment lancer le projet
